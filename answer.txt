3) 5 && "qwerty" // відповідь буде "qwerty"  бо 5 - True та  "qwerty" - True, то виведе друге True.

4) +'40' + +'2' + "hillel"; // відповідь буде "42hillel". Так як перед '40' стоїть знак + то значення стає числом, те саме стосується і '2', тому порахується сума 40+2=42. А з "hillel" воно сконкатенується.

5) '10' - 5 === 6; // відповідь "False", спочатку відбудеться неявне перетворення '10' типу string на 10 типу number, потім 10-5=5. Далі відбувається порівняння типів значень, в нашому випадку 5 та 6 мають однаковий тип значення number, але 5 не дорівнює 6.

6) true + false // відповідь "1". Спочатку відбудеться неявне перетворення, тобто true = 1, а false = 0, далі рахується сума.

7) '4px' - 3 // відповідь "NaN".  Так як '4px' тип string і складається як з цифри так і з літер то неявне перетворення в тип number не відбудеться.

8) '4' - 3 //відповідь "1". Відбудеться неявне перетворення з типу string в тип number, 4 - 3 =1.

9) '6' + 3 ** 0; // відповідь "61". Сочатку введемо 3 в ступінь 0 це буде 1. Так як знак + зазвичай конкатинує рядки.

10) 12 / '6' // відповідь "2". Відбудеться перетворення '6' в число, далі 12/6=2.

11) '10' + (5 === 6); // відповідь "10False". Спочатку відбуваються дії в душках, порівнюємо типи та значення, 5 та 6 мають тип number, але 5 не дорівнює 6 тому буде false. '10' це рядок тому ці два значення сконкатенуються.

12)null == '' // відповідь "False". Порівнюються значення null = 0, а '' = нічому.

13) 3 ** (9 / 3); // відпвідь "27". Спочатку дії в душках 9/3 = 3. Даль 3 необхідно ввести в ступінь 3.

14) !!'false' == !!'true' // відповідь "True". 'false' має тип string, !'false' переводе в тип boolean та інвертує тобто стає false, а якщо додати ! до false то стане true. Тобто !!'false' є true, те саме з !!'true' воно залишається true. true = true.

15) 0 || '0' && 1 // відповідь "1". Спочатку відбувається строге порівняння. '0' && 1 має два true тому виведе останне true тобто 1. Потім відбувається не строге порівняння 0 || 1, має два true, тому виведе останнє true.

16) (+null == false) < 1; // відповідь "False". Спочатку дії в дужках, +null це число 0, false це число 0, тому в дужках видасть true. 1 = true. Але true < true не може бути.

17) false && true || true // відповідь "True". Спочатку відбувається строге порівняння і має false. Далі йде нестроге порівння і там вже маємо True.

18) false && (false || true); // відповідь "False". Спочатку дії в душках, нестроге порівняння тому маємо true. Далі строге порівняння, маємо false.

19) (+null == false) < 1 ** 5; // відповідь "False". Спочатку дії в дужках, +null це число 0, false це число 0, тому в дужках видасть true. 1 вводимо у 5 ступінь = 1 і це true. Але true < true не може бути.
